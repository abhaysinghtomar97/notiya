Mathematical & Statistical Foundations

Statistics in code
import numpy as np x = np.array([2, 4, 4, 4, 5, 5, 7, 9]) print(x.mean(), x.std(), np.median(x)) A = np.array([[1, 2], [3, 4]]) v = np.array([1, 1]) print(A @ v) # matrix-vector product
RememberBayes' theorem: P(A|B) = P(B|A) · P(A) / P(B). It updates a belief after seeing evidence.

Data Preprocessing & Feature Engineering

Models learn from numbers. Real data has gaps, text categories, and wildly different scales. Good preprocessing often matters more than the choice of algorithm.

ProblemFix
Missing valuesDrop rows, or impute with mean / median / most frequent
Categories as textOne-hot encoding (no order) or ordinal encoding (has order)
Different scalesMin-max scaling or standardization
OutliersIQR rule, clipping, or a log transform
Too many featuresFeature selection, PCA
from sklearn.impute import SimpleImputer from sklearn.preprocessing import StandardScaler import numpy as np X = np.array([[25.0], [np.nan], [35.0]]) X = SimpleImputer(strategy="mean").fit_transform(X) print(X.ravel())

Same ages, three views. Standardization centers the column at 0 with spread 1; min-max squeezes it into 0 to 1.

Feature engineering
Combine price / area → price per sqftExtract date → month, weekdayBin age → age groupTransform log(income)Interact x1 · x2
Data leakageFit the scaler or imputer on the training set only, then transform the test set. Fitting on all data leaks test information into training and inflates your score.

Supervised Learning

You give the model inputs X and known answers y. It learns the mapping. Predicting a number is regression; predicting a category is classification.

AlgorithmTypeIdea
Linear RegressionRegressionFit the best straight line by minimizing squared error
Logistic RegressionClassificationLine squashed by a sigmoid into a probability
KNNBothVote among the k closest training points
SVMBothWidest-margin boundary between classes
Naive BayesClassificationBayes' theorem with independent features
Decision TreeBothChain of yes/no questions on features
Random ForestBothMany trees on random samples, averaged
Gradient Boosting (XGBoost)BothTrees built one after another, each fixing the last one's errors

Unsupervised Learning

No labels. The model finds structure on its own: groups of similar rows (clustering) or fewer, richer features (dimensionality reduction).

MethodUseNote

Playground: K-Means, step by step

Each click alternates between two moves: assign every point to its nearest centroid, then update each centroid to the mean of its points.

from sklearn.cluster import KMeans X = [[1, 1], [1.5, 2], [8, 8], [9, 9]] print(KMeans(n_clusters=2, n_init=10, random_state=0).fit_predict(X)) from sklearn.decomposition import PCA X = [[1, 2], [2, 4], [3, 6]] # second feature is just 2x the first print(PCA(n_components=1).fit(X).explained_variance_ratio_)
TipPick k with the elbow method (plot inertia vs k) or the silhouette score. Always scale features first, since K-Means and PCA are distance and variance based.

Playground: the threshold trade-off

A classifier outputs scores. Where you cut them decides the trade-off between precision and recall.

Common mistakeJudging a fraud model by accuracy when only 1% of cases are fraud. Predicting "not fraud" every time scores 99%. Use recall, precision, and F1.
Overfitting & generalization
ProblemSymptomRemedy
Underfitting (high bias)Poor on train and testMore features, a more flexible model
Overfitting (high variance)Great on train, poor on testMore data, regularization, simpler model, early stopping
from sklearn.model_selection import cross_val_score, GridSearchCV from sklearn.linear_model import Ridge # L2 regularization scores = cross_val_score(Ridge(), X, y, cv=5) # 5-fold CV grid = GridSearchCV(Ridge(), {"alpha": [0.1, 1, 10]}, cv=5).fit(X, y) print(grid.best_params_)
RememberSplit data into train, validation, and test. Tune on validation (or with cross-validation); touch the test set once, at the end. L1 (Lasso) can zero out features; L2 (Ridge) shrinks them.

Deep Learning & Specialized Domains

A neural network stacks layers of simple units. Each unit computes output = activation(w · x + b). Training adjusts the weights by backpropagation plus gradient descent.
