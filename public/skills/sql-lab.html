SQL & The Lab Dataset

SQL (Structured Query Language) is how you create, change, and question data stored in relational databases like MySQL, PostgreSQL, and SQLite. Its commands fall into sub-languages:

TypeStands forCommandsPurpose
DDLData DefinitionCREATE, ALTER, DROP, TRUNCATEBuild and change structure
DMLData ManipulationINSERT, UPDATE, DELETEChange the rows
DQLData QuerySELECTRead data
TCLTransaction ControlBEGIN, COMMIT, ROLLBACK, SAVEPOINTSave or undo groups of changes
DCLData ControlGRANT, REVOKEPermissions
Note"TQL" is not a standard SQL category. This course covers DQL (queries), which is what people usually mean, alongside TCL.

Constraints

Constraints are rules the database enforces so bad data never gets in.

PRIMARY KEY unique + not nullFOREIGN KEY must match a parent rowUNIQUE no duplicatesNOT NULL value requiredCHECK custom ruleDEFAULT fallback value
CREATE TABLE employees ( emp_id INT PRIMARY KEY AUTO_INCREMENT, name VARCHAR(50) NOT NULL, email VARCHAR(80) UNIQUE, dept_id INT, salary DECIMAL(10,2) CHECK (salary > 0), city VARCHAR(30) DEFAULT 'Delhi', FOREIGN KEY (dept_id) REFERENCES departments(dept_id) ); INSERT INTO employees (emp_id, name, salary) VALUES (1, 'Duplicate Dan', 50000); -- emp_id 1 already exists
Common mistakeStoring money in FLOAT. Rounding errors creep in. Use DECIMAL.

DDL: Defining Structure

DDL changes the shape of the database, not the rows inside. In MySQL, DDL commands commit automatically and cannot be rolled back.

CREATE DATABASE company; USE company; CREATE TABLE departments ( dept_id INT PRIMARY KEY, dept_name VARCHAR(40) NOT NULL ); ALTER TABLE employees ADD COLUMN age INT; -- add ALTER TABLE employees MODIFY COLUMN name VARCHAR(80); -- change type ALTER TABLE employees DROP COLUMN age; -- remove ALTER TABLE employees RENAME TO staff; -- rename table
CommandRemovesKeeps structure?
TRUNCATEAll rows, fastYes
DROP TABLERows and the table itselfNo
TRUNCATE TABLE employees; DROP TABLE IF EXISTS employees;

DML: Changing Data

INSERT INTO departments VALUES (1,'Engineering'),(2,'Marketing'),(3,'Finance'),(4,'HR'); INSERT INTO employees (name, dept_id, salary, city) VALUES ('Aman Verma', 1, 72000, 'Delhi'), ('Riya Shah', 2, 58000, 'Mumbai'); UPDATE employees SET salary = salary * 1.10 WHERE dept_id = 1; DELETE FROM employees WHERE name = 'Vikram Rao';
DangerUPDATE or DELETE without WHERE hits every row. Write the WHERE first, or test it as a SELECT.
RememberDELETE removes chosen rows and can be rolled back. TRUNCATE empties the table and usually cannot.

Aggregation & Grouping


Aggregate functions collapse many rows into one value: COUNT SUM AVG MIN MAX. GROUP BY does it once per group.

SELECT COUNT(*) AS total, AVG(salary) AS avg_sal, MAX(salary) AS top
FROM employees;

RememberCOUNT(*) counts rows. COUNT(col) skips NULLs. Aggregates ignore NULL values.


ClauseFiltersRuns

Joins


A join matches rows from two tables using a shared column, here dept_id. The join type decides what happens to rows with no match.




TipFULL JOIN is not in MySQL. Emulate it with LEFT JOIN ... UNION ... RIGHT JOIN.







Subqueries


A subquery is a SELECT nested inside another query. The inner query runs first and feeds the outer one.

-- Who earns more than the company average?
SELECT name, salary FROM employees
WHERE salary > (SELECT AVG(salary) FROM employees);
-- Employees in departments based on this list
SELECT name FROM employees
WHERE dept_id IN (SELECT dept_id FROM departments
                  WHERE dept_name IN ('Finance','HR'));
-- Departments that have at least one employee (correlated)
SELECT dept_name FROM departments d
WHERE EXISTS (SELECT 1 FROM employees e WHERE e.dept_id = d.dept_id);

InsightMany subqueries can be rewritten as JOINs, which are often faster. Use a subquery when it reads more clearly.







TCL: Transactions


A transaction groups statements so they succeed together or not at all (ACID: Atomicity, Consistency, Isolation, Durability).

BEGIN;
UPDATE accounts SET balance = balance - 500 WHERE id = 1;
SAVEPOINT after_debit;
UPDATE accounts SET balance = balance + 500 WHERE id = 2;
COMMIT;   -- or ROLLBACK; / ROLLBACK TO after_debit;

More Important Concepts


Views & indexes

CREATE VIEW high_earners AS
SELECT name, salary FROM employees WHERE salary >= 70000;
CREATE INDEX idx_city ON employees(city);  -- faster lookups by city

TipA view is a saved query. An index speeds up reads on a column but slows writes slightly, so index columns you filter or join on often.


CTEs & window functions

WITH ranked AS (
  SELECT name, salary, RANK() OVER (ORDER BY salary DESC) AS rnk
  FROM employees
)
SELECT * FROM ranked WHERE rnk <= 3;

Also worth learning next: UNION, COALESCE for NULLs, string and date functions, EXPLAIN for performance, and normalization.
